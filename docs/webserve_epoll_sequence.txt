	┌──────────────────────────────────────────────┐
	│ STEP 1 — RECEIVE + RECONSTRUCT HTTP REQUEST  │
	└──────────────────────────────────────────────┘

	CLIENT
	│
	│ sends TCP packets
	▼

	TRANSPORT LAYER
	│
	├─ epoll says socket is readable
	│
	├─ recv() available bytes
	│
	├─ append bytes into client read buffer
	│
	├─ check:
	│      "\r\n\r\n" found ?
	│
	├─ NO
	│      request headers incomplete
	│      wait for more bytes
	│
	└─ YES
			headers complete
			parse Content-Length
			determine expected body size

				│
				├─ body incomplete
				│      wait for more recv()
				│
				└─ body complete
						FULL HTTP REQUEST READY




	┌──────────────────────────────────────────────┐
	│ STEP 2 — PROCESS REQUEST + SEND RESPONSE    │
	└──────────────────────────────────────────────┘

	HTTP LAYER
	│
	├─ parse method
	├─ parse path
	├─ parse headers
	├─ validate request
	├─ route request
	├─ optional CGI execution
	├─ generate response body
	└─ generate full HTTP response

				│
				▼

	TRANSPORT LAYER
	│
	├─ place response into write buffer
	│
	├─ epoll says socket writable
	│
	├─ send() response bytes
	│
	├─ partial write ?
	│      YES → keep remaining bytes
	│             continue later
	│
	└─ full response sent
			│
			├─ keep-alive ?
			│      YES → reset client state
			│             wait for next request
			│
			└─ NO → close connection




	┌──────────────────────────────────────────────┐
	│ COMPLETE SERVER FLOW                        │
	└──────────────────────────────────────────────┘

	epoll_wait()
		│
		▼
	socket event detected
		│
		├─ listening socket
		│      └─ accept new client
		│
		└─ client socket
			│
			├─ readable
			│      └─ recv() bytes
			│
			├─ reconstruct HTTP request
			│
			├─ request complete ?
			│      NO → continue waiting
			│
			└─ YES
					│
					▼
				HTTP processing
					│
					▼
				generate response
					│
					▼
				writable socket
					│
					▼
				send() response
					│
					├─ partial send
					│      └─ continue later
					│
					└─ complete
							│
							├─ keep alive
							│      └─ wait again
							│
							└─ close socket
