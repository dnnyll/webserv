loop coordination:

1. connection lifecycle
2. read readiness
3. write readiness
4. client state
5. buffering
6. cleanup

example:

now:

Client 42:

socket fd: 42

read buffer:
"GET /inde"

state:
READING_HEADERS


then:

read buffer:
"GET /index.html HTTP/1.1\r\nHost:"

still incomplete


then:

read buffer:
"GET /index.html HTTP/1.1\r\nHost: x\r\n\r\n"

headers complete


loop transitions:

READING_HEADERS
        ↓
HEADERS_COMPLETE
        ↓
READING_BODY
        ↓
REQUEST_COMPLETE
        ↓
GENERATING_RESPONSE
        ↓
WRITING_RESPONSE
        ↓
DONE
