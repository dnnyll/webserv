before loop poll() starts:

parse config
    → open sockets for each server block
        → bind each socket to its port
            → listen on each socket
                → hand all socket fds to poll()

during loop poll():

recv() bytes → buffer complete? → Person C parses + processes → send() response

once the full sequence of bytes has been received


1. parse it       → extract method, path, headers, body into clean struct
2. figure out     → which server block? which location?
3. do the work    → GET/POST/DELETE
4. build response → status code + headers + body
5. hand back      → raw response string ready to send

simple GET request example:

GET /index.html HTTP/1.1\r\n
Host: localhost:8080\r\n
User-Agent: Chrome\r\n
\r\n

POST with form submission example:

POST /login HTTP/1.1\r\n
Host: localhost:8080\r\n
Content-Type: application/x-www-form-urlencoded\r\n
Content-Length: 27\r\n
\r\n
username=alice&password=1234

file upload example:

POST /upload HTTP/1.1\r\n
Host: localhost:8080\r\n
Content-Type: image/jpeg\r\n
Content-Length: 52428\r\n
\r\n
[52428 bytes of raw image data]


answer example:

HTTP/1.1 200 OK\r\n
Content-Type: text/html\r\n
Content-Length: 42\r\n
\r\n
<html>Hello from webserv</html>

part 1 - status Line:		HTTP/1.1 200 OK
part 2 - response headers:	Content-Type: text/html\r\n
							Content-Length: 42\r\n
part 3 - body:				<html>Hello from webserv</html>

what the server does:

1. New client connecting

a listening socket is ready
→ accept()
→ create new client fd
→ add that fd to poll() watch list

2. Existing client sending data
a client fd is ready to read
→ recv() → append to that client's buffer
→ check if request is complete
→ if yes → hand to Person C
→ if no → wait for more data

3. Response ready to send
a client fd is ready to write
→ send() the response
→ if keep-alive → keep fd in poll(), wait for next request
→ if not → close fd, remove from poll()

4. CGI script running
a CGI pipe fd is ready to read
→ read script output
→ when done → build response
→ send() back to client
→ waitpid() to clean up child process
→ remove pipe fd from poll()

5. Client disconnected
recv() returns 0
→ client closed connection
→ close fd
→ remove from poll()

6. Timeouts
on every poll() cycle check timestamps
→ client taking too long to send → close it, 408
→ CGI script taking too long → kill it, 504
