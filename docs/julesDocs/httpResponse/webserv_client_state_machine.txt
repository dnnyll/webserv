[TOUR POLL N°1] -> Détecte POLLIN sur le FD du Client
       |
       v
+---------------------------------------------------------------------------------+
| ÉTAT DU CLIENT : [ READING ]                                                    |
|                                                                                 |
| 1. OS Read :                                                                    |
|    read(FD, buf) a lu "GET / HTTP/1"                                            |
|                                                                                 |
| 2. Stockage :                                                                   |
|    Client::_raw_data += buf;                                                    |
|                                                                                 |
| 3. Tentative de Parsing :                                                       |
|    HttpRequest::isComplete() -> Faux (pas de \r\n\r\n)                          |
|                                                                                 |
| => FIN DU TOUR, le serveur retourne gérer d'autres trucs dans poll()            |
+---------------------------------------------------------------------------------+

[TOUR POLL N°34] -> Détecte POLLIN sur le FD du Client (Le réseau n'est plus lent)
       |
       v
+---------------------------------------------------------------------------------+
| ÉTAT DU CLIENT : [ READING ]                                                    |
|                                                                                 |
| 1. OS Read :                                                                    |
|    read(FD, buf) a lu ".1\r\nHost: loc...\r\n\r\n"                              |
|                                                                                 |
| 2. Stockage :                                                                   |
|    Client::_raw_data += buf;                                                    |
|                                                                                 |
| 3. Tentative de Parsing :                                                       |
|    HttpRequest::isComplete() -> VRAI ! On a trouvé le \r\n\r\n.                 |
|    -> Le parseur extrait tout (Method, URI, Body) dans l'objet HttpRequest !    |
|                                                                                 |
| ====> CHANGEMENT D'ÉTAT : On passe à [ PROCESSING ] <====                       |
+---------------------------------------------------------------------------------+

[TOUR POLL N°35] -> (Généralement traité dans la foulée sans attendre poll() )
       |
       v
+---------------------------------------------------------------------------------+
| ÉTAT DU CLIENT : [ PROCESSING ]                                                 |
|                                                                                 |
| 1. Routage / Action :                                                           |
|    On lit le dossier configuré pour l'URI demandée (ex: fichier /var/www/...)   |
|                                                                                 |
| 2. Génération de la Réponse :                                                   |
|    L'objet HttpResponse se construit (Status 200, Content-Type, etc.)           |
|                                                                                 |
| 3. Sérialisation (Le moment clé) :                                              |
|    Client::_write_buffer = HttpResponse::toString() + Le_Fichier_Lu             |
|                                                                                 |
| 4. Demande au système :                                                         |
|    "Mets à jour mon pollfd ! Je ne veux plus POLLIN, je veux POLLOUT !"         |
|                                                                                 |
| ====> CHANGEMENT D'ÉTAT : On passe à [ WRITING ]  <====                         |
+---------------------------------------------------------------------------------+

[TOUR POLL N°36] -> Détecte POLLOUT sur le FD du Client (On a le droit d'envoyer)
       |
       v
+---------------------------------------------------------------------------------+
| ÉTAT DU CLIENT : [ WRITING ]                                                    |
|                                                                                 |
| 1. OS Write :                                                                   |
|    int sent = write(FD, Client::_write_buffer)                                  |
|    L'OS réussit à envoyer 2000 octets.                                          |
|                                                                                 |
| 2. Mise à jour du buffer :                                                      |
|    Client::_write_buffer.erase(0, sent) // On efface ce qui a été envoyé        |
|                                                                                 |
| 3. Vérification :                                                               |
|    Le _write_buffer est-il vide ?                                               |
|    - NON : OK, on attendra le prochain tour POLLOUT pour envoyer la suite.      |
|    - OUI : Réponse totalement envoyée !                                         |
|                                                                                 |
| ====> SI OUI (FIN DU TRAITEMENT) :                                              |
|       - Option A (Keep-Alive) : On remet l'état à [ READING ], on vide          |
|         HttpRequest/HttpResponse, et on redemande POLLIN.                       |
|       - Option B (Close) : On ferme(FD) et on tue l'objet Client.               |
+---------------------------------------------------------------------------------+
