This is how we get Config  -> client_max_body_size all the way to HttpRquest _maxBodySize

ServerBlock.client_max_body_size
         │
         │  passed by const reference
         ▼
AcceptHandler._serverBlock
         │
         │  passed to ClientHandler on accept()
         ▼
ClientHandler
    _request.setMaxBodySize(block.client_max_body_size)
         │
         │  stored as private member
         ▼
HttpRequest._maxBodySize
         │
         │  checked at start of function
         ▼
decodeBody()
    if (contentLength > _maxBodySize) → ERROR_STATE
