                         IEventHandler (abstract)
                    handleRead() / handleWrite()
                    getFd() / shouldClose()
                              │
              ┌───────────────┴───────────────┐
              ▼                                ▼
      AcceptHandler                     ClientHandler   
      (listening socket)                (one per client connection)
      ─────────────────                 ─────────────────
      handleRead():                     handleRead():
        accept()                          recv() → request.getData()
        → new ClientHandler                → checks hasError/isComplete
        → reactor.addHandler(it)
                                         handleWrite():
      handleWrite(): unused                send(_outBuffer)
                                            → keep-alive reset OR shouldClose
      shouldClose(): always false
                                          owns: HttpRequest

                              ▲
                              │ both registered in
                              ▼

                          EventLoop
                       (the Reactor itself)
                       ─────────────────
                       owns: vector<IEventHandler*>

                       run():
                         loop:
                           1. build pollfd[] from all handlers
                           2. poll(pollfd[])
                           3. for each ready fd:
                                find matching handler
                                POLLIN  → handleRead()
                                POLLOUT → handleWrite()
                           4. remove + delete handlers
                              where shouldClose() == true
