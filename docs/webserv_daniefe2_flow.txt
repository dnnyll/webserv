STARTUP
───────
main()
  │
  ├── EventLoop reactor
  ├── AcceptHandler listener(8080, reactor)
  │     └── setupSocket(8080)
  │           ├── socket()        — create listening fd
  │           ├── setsockopt()    — allow port reuse
  │           ├── bind()          — assign port 8080
  │           ├── listen()        — start accepting connections
  │           └── fcntl()         — set non-blocking
  │
  ├── reactor.addHandler(&listener)
  │     └── _handlers.push_back(&listener)
  │
  └── reactor.run()


EVENT LOOP — runs forever
─────────────────────────
while (true)
  │
  ├── buildPollFds()
  │     └── for each handler in _handlers:
  │           create struct pollfd
  │           fd     = handler->getFd()
  │           events = POLLIN
  │           events |= POLLOUT  if handler->isWritable()
  │           push into _pollfds
  │
  ├── poll(&_pollfds[0], _pollfds.size(), -1)
  │     └── OS blocks until any fd is ready
  │         fills revents on ready entries
  │         returns number of ready fds
  │
  ├── dispatch()
  │     └── for each _pollfds[i]:
  │           if POLLIN  → _handlers[i]->handleRead()
  │           if POLLOUT → _handlers[i]->handleWrite()
  │           if POLLERR → _handlers[i]->setClose()
  │
  └── removeClosedHandlers()
        └── for each handler:
              if setClose() → delete handler
                             erase from _handlers


NEW CLIENT CONNECTS — inside dispatch() → POLLIN on listening fd
────────────────────────────────────────────────────────────────
AcceptHandler::handleRead()
  │
  ├── accept(_fd)          — creates new clientFd
  ├── new ClientHandler(clientFd)
  │     └── constructor:
  │           _fd         = clientFd
  │           _keepAlive  = true
  │           _isClosed   = false
  │           _chunkSize  = 0
  │
  └── _reactor.addHandler(client)
        └── _handlers.push_back(client)
            (next buildPollFds() will include this fd)


CLIENT SENDS REQUEST — inside dispatch() → POLLIN on client fd
───────────────────────────────────────────────────────────────
ClientHandler::handleRead()
  │
  ├── recv(_fd, buffer, 4096)    — read raw bytes from socket
  │
  ├── if bytesReceived <= 0
  │     └── _isClosed = true     — disconnect or error
  │
  └── _request.getData(chunk)
        │
        ├── _buffer += chunk     — accumulate raw bytes
        │
        └── while state != COMPLETE && state != ERROR_STATE:
              decode()
                │
                ├── case REQUEST_LINE → decodeRequestLine()
                │     ├── skip leading \r\n
                │     ├── extractRequestLine()
                │     │     └── find \r\n in _buffer
                │     │         extract line, erase from _buffer
                │     ├── splitRequestLine()
                │     │     ├── find first space  → method
                │     │     ├── find second space → uri
                │     │     └── remainder         → version
                │     ├── validateRequestLine()
                │     │     ├── method must be GET/POST/DELETE
                │     │     ├── uri must start with /
                │     │     └── version must be HTTP/1.1
                │     └── _state = HEADERS
                │
                ├── case HEADERS → decodeHeaders()
                │     └── loop:
                │           find \r\n in _buffer
                │           if pos == 0 → blank line → end of headers
                │             └── resolveBodyState()
                │                   ├── Transfer-Encoding: chunked → _state = CHUNKED
                │                   ├── Content-Length present     → _state = BODY
                │                   └── neither                    → _state = COMPLETE
                │           else → split by ": " → headers[key] = value
                │                  erase line from _buffer
                │
                ├── case BODY → decodeBody()
                │     ├── bytesNeeded  = contentLength - _bodyBytesRead
                │     ├── toRead       = min(bytesNeeded, available)
                │     ├── body        += _buffer.substr(0, toRead)
                │     ├── _buffer.erase(0, toRead)
                │     └── if _bodyBytesRead == contentLength → _state = COMPLETE
                │
                └── case CHUNKED → decodeChunked()
                      └── loop:
                            if _chunkSize == 0:
                              find \r\n → parse hex size → _chunkSize
                              if _chunkSize == 0 → _state = COMPLETE
                            else:
                              wait until _buffer.size() >= _chunkSize + 2
                              body += _buffer.substr(0, _chunkSize)
                              _buffer.erase(0, _chunkSize + 2)
                              _chunkSize = 0


REQUEST COMPLETE
────────────────
ClientHandler::handleRead()  (continued)
  │
  ├── if _request.hasError()
  │     └── _outBuffer = error response    (400/505 — Router/HttpResponse)
  │
  └── if _request.isComplete()
        └── _outBuffer = Router::route(_request).serialize()
            (currently: fake "HTTP/1.1 200 OK\r\n...")


SERVER SENDS RESPONSE — inside dispatch() → POLLOUT on client fd
─────────────────────────────────────────────────────────────────
ClientHandler::handleWrite()
  │
  ├── if _outBuffer.empty() → return
  │
  ├── send(_fd, _outBuffer)     — write bytes to socket
  │
  ├── _outBuffer.erase(0, bytesSent)   — consume what was sent
  │
  └── if _outBuffer.empty():
        ├── if _keepAlive → _request.reset()   — ready for next request
        │     ├── clear method/uri/version/headers/body
        │     ├── _state = REQUEST_LINE
        │     ├── _bodyBytesRead = 0
        │     ├── _chunkSize = 0
        │     └── (keep _buffer — may have pipelined request bytes)
        │
        └── else → _isClosed = true
              └── removeClosedHandlers() will delete this ClientHandler
