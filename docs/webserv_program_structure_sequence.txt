▼

│
├── poll(pollfds, timeout)
├── if EINTR → continue
├── iterate active fds

│
├── dispatch:
│       POLLIN        → handle_input()

├── apply deferred add list
│

        any ClientHandler alive too long → handle_close()

Router::route()  (stateless free function — never instantiated)
│
├── filter configs by ip:port
├── match Host header → pick ServerConfig (first = default)
├── match URI → pick LocationConfig (exact first, then prefix)
├── validate method → 405 if not in allowedMethods
├── detect request type
│
├───────────────────────────────────────────────────────────┐
│  REDIRECT                                                 │
│    build 301/302 HttpResponse                             │
│    no filesystem access needed                            │
│    → go to phase 7                                        │
├───────────────────────────────────────────────────────────┤
│  STATIC FILE  (GET)                                       │
│    FileSystem::readFile(path)                             │
│    FileSystem::mimeType(extension)                        │
│    if directory → find index or FileSystem::autoindex()   │
│    build 200 HttpResponse                                 │
│    → go to phase 7                                        │
├───────────────────────────────────────────────────────────┤
│  UPLOAD  (POST)                                           │
│    FileSystem::writeFile(path, body)                      │
│    build 201 HttpResponse                                 │
│    → go to phase 7                                        │
├───────────────────────────────────────────────────────────┤
│  DELETE                                                   │
│    FileSystem::deleteFile(path)                           │
│    build 200 HttpResponse                                 │
│    → go to phase 7                                        │
├───────────────────────────────────────────────────────────┤
│  CGI                                                      │
│    signal CGI needed                                      │
│    → go to phase 8 (CGI path)                             │
├───────────────────────────────────────────────────────────┤
│  ERROR  (400 / 403 / 404 / 405 / 413 / 500)               │
│    check errorPages map → custom page if set              │
│    fallback to built-in default error page                │
│    build error HttpResponse                               │
│    → go to phase 7                                        │
└───────────────────────────────────────────────────────────┘
