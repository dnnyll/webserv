  PART 1 — WHAT DEV B IS RESPONSIBLE FOR
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  DEV B owns everything between raw bytes arriving and a response
  being ready to send. no sockets, no files, pure logic.


  ┌──────────────────────────────────────────────────────────────┐
  │  HttpRequest                                                 │
  └──────────────────────────────────────────────────────────────┘
  │
  ├── owns the full implementation of feed() and isComplete()
  │
  ├── ParseState machine
  │       REQUEST_LINE
  │         read until \r\n
  │         extract method, URI, version
  │         reject unknown methods → mark 400
  │
  │       HEADERS
  │         read Key: Value\r\n lines
  │         stop at blank line \r\n\r\n
  │         store in headers map
  │         extract Content-Length → store as size_t
  │         check body size vs maxBodySize → mark 413
  │
  │       BODY
  │         read exactly Content-Length bytes
  │         no chunked — HTTP/1.0 only
  │
  │       COMPLETE
  │         isComplete() returns true
  │         ClientHandler moves to routing
  │
  ├── must survive partial delivery
  │       data arrives in chunks across multiple recv() calls
  │       feed() called each time — must resume correctly
  │       state and leftover bytes must persist between calls
  │
  └── must never block or do I/O — only processes the string given


  ┌──────────────────────────────────────────────────────────────┐
  │  HttpResponse                                                │
  └──────────────────────────────────────────────────────────────┘
  │
  ├── owns serialize()
  │       produces raw HTTP/1.0 byte string
  │       format:
  │         "HTTP/1.0 {statusCode} {statusMsg}\r\n"
  │         "{header}: {value}\r\n"  for each header
  │         "\r\n"
  │         body
  │
  ├── must always include:
  │       Content-Length: {body.size()}
  │       Connection: close
  │
  └── must provide helpers to build common responses
          200 OK          → static file response
          201 Created     → upload response
          301/302         → redirect response
          400 Bad Request → malformed request
          403 Forbidden   → no read permission
          404 Not Found   → file not found
          405 Not Allowed → method not in allowedMethods
          413 Too Large   → body exceeds maxBodySize
          500 Internal    → server error fallback


  ┌──────────────────────────────────────────────────────────────┐
  │  Router                                                      │
  └──────────────────────────────────────────────────────────────┘
  │
  ├── stateless — never instantiated, free function only
  │       Router::route(request, configs, ip, port) → HttpResponse
  │
  ├── step 1 — select ServerConfig
  │       filter configs whose listens contain ip:port
  │       match Host header against serverNames
  │       no match → use first config on that port (default)
  │
  ├── step 2 — select LocationConfig
  │       check exact matches (isExact=true) first
  │       then longest prefix match
  │       no match → 404
  │
  ├── step 3 — validate method
  │       check request.method against location.allowedMethods
  │       not listed → 405
  │
  ├── step 4 — decide response source
  │
  │   redirectCode set
  │       build 301/302 HttpResponse
  │       set Location header to redirectUri
  │       return immediately — no filesystem needed
  │
  │   URI extension in cgiExtensions
  │       return a CGI_NEEDED signal to ClientHandler
  │       does not build HttpResponse here
  │       ClientHandler handles the fork/pipe side
  │
  │   GET — static file or directory
  │       call FileSystem::readFile(path) → body + mime
  │       if path is directory:
  │           look for index file first
  │           if autoindex on → call FileSystem::autoindex()
  │           if autoindex off → 403
  │       build 200 HttpResponse
  │
  │   POST — upload
  │       check uploadStore is set → 405 if not
  │       call FileSystem::writeFile(uploadStore, body)
  │       build 201 HttpResponse
  │
  │   DELETE
  │       call FileSystem::deleteFile(path)
  │       build 200 HttpResponse
  │
  │   any error
  │       check config.errorPages for custom page path
  │       if found → call FileSystem::readFile(customPath)
  │       if not found → use built-in default error body
  │       build 4xx/5xx HttpResponse
  │
  └── step 5 — return HttpResponse to ClientHandler

  │  ──────────────────────────────────────────────────────────  │
  │  string  host                                                │
  │  int     port                                                │
  │                                                              │
  │  why B needs it:                                             │
  │    Router filters configs by matching ip:port                │
  │    against each ListenEntry in ServerConfig.listens          │
  └──────────────────────────────────────────────────────────────┘

  │  ──────────────────────────────────────────────────────────  │

  │  vector      allowedMethods                                  │

  │  map  cgiExtensions                                          │
  │  string              uploadStore                             │
  │  int                 redirectCode                            │
  │  string              redirectUri                             │
  │                                                              │
  │  why B needs it:                                             │
  │    Router reads every field to make routing decisions        │
  │    B reads this struct more than anyone else                 │
  └──────────────────────────────────────────────────────────────┘

  ┌──────────────────────────────────────────────────────────────┐
  │  ServerConfig                                                │
  │  ──────────────────────────────────────────────────────────  │
  │  vector     listens                                          │
  │  vector          serverNames                                 │
  │  size_t                  maxBodySize                         │
  │  map         errorPages                                      │
  │  vector  locations                                           │
  │                                                              │
  │  why B needs it:                                             │
  │    Router receives vector as its main input                  │
  │    maxBodySize needed in HttpRequest to check 413            │
  │    errorPages needed to find custom error page paths         │
  └──────────────────────────────────────────────────────────────┘


  FROM DEV C  (stubs at first, real impl later)
  ┌──────────────────────────────────────────────────────────────┐

  │  bool    deleteFile(path)       returns success              │
  │  string  autoindex(path, uri)   returns HTML listing         │
  │                                                              │
  │  why B needs it:                                             │
  │    Router calls these for GET / POST / DELETE / autoindex    │
  │    B never touches open() or read() directly                 │
  │    C implements these, B just calls them                     │
  └──────────────────────────────────────────────────────────────┘

  PART 3 — WHAT DEV A AND DEV C DEPEND ON FROM B
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━


  WHAT DEV A NEEDS FROM B
  ┌──────────────────────────────────────────────────────────────┐
  │  HttpRequest::feed(string chunk) → bool                      │
  │  ──────────────────────────────────────────────────────────  │
  │  called inside ClientHandler::handle_input()                 │
  │  after every recv()                                          │
  │  A does not care how it works — just calls it                │
  │                                                              │
  │  what A needs from the signature:                            │
  │    takes a string chunk                                      │
  │    returns bool — true means complete, false means keep going│
  └──────────────────────────────────────────────────────────────┘

  ┌──────────────────────────────────────────────────────────────┐
  │  HttpRequest::isComplete() → bool                            │
  │  ──────────────────────────────────────────────────────────  │
  │  called inside ClientHandler::handle_input()                 │
  │  after feed() to decide whether to call Router               │
  └──────────────────────────────────────────────────────────────┘

  ┌──────────────────────────────────────────────────────────────┐
  │  Router::route(request, configs, ip, port) → HttpResponse    │
  │  ──────────────────────────────────────────────────────────  │
  │  called inside ClientHandler::handle_input()                 │
  │  when isComplete() is true                                   │
  │  A takes the returned HttpResponse, calls serialize(),       │
  │  writes result into _writeBuf, calls reactor.modify(POLLOUT) │
  │                                                              │
  │  special case A must handle:                                 │
  │    if Router signals CGI needed (not a full HttpResponse)    │
  │    A creates CgiHandler, registers pipe into Reactor         │
  └──────────────────────────────────────────────────────────────┘

  ┌──────────────────────────────────────────────────────────────┐
  │  HttpResponse::serialize() → string                          │
  │  ──────────────────────────────────────────────────────────  │
  │  called inside ClientHandler after route() returns           │
  │  result written into _writeBuf                               │
  │  A never builds an HttpResponse — only serializes one        │
  └──────────────────────────────────────────────────────────────┘


  WHAT DEV C NEEDS FROM B
  ┌──────────────────────────────────────────────────────────────┐
  │  HttpRequest  (read-only access)                             │
  │  ──────────────────────────────────────────────────────────  │
  │  string  body      piped to CGI stdin for POST requests      │
  │  string  uri       used to build PATH_INFO env var           │
  │  string  method    used to build REQUEST_METHOD env var      │
  │  map     headers   used to build CONTENT_TYPE env var        │
  │  size_t  contentLength  used for CONTENT_LENGTH env var      │
  │                                                              │
  │  C never calls feed() or isComplete()                        │
  │  C only reads the final populated fields                     │
  └──────────────────────────────────────────────────────────────┘

  ┌──────────────────────────────────────────────────────────────┐
  │  Router CGI signal                                           │
  │  ──────────────────────────────────────────────────────────  │
  │  when Router decides CGI is needed it must communicate this  │
  │  to ClientHandler (A) who then triggers C's CgiHandler       │
  │                                                              │
  │  agreed mechanism — one of these two options:                │
  │    option 1: Router returns a special HttpResponse           │
  │              with statusCode = 0 meaning "CGI pending"       │
  │    option 2: Router returns a bool isCgi flag alongside      │
  │              a populated LocationConfig for the script path  │
  │                                                              │
  │  B and A must agree on which before coding starts            │
  └──────────────────────────────────────────────────────────────┘
