webserv // suite active

HTTP test suite -- webserv

Tests: GET, POST, DELETE, UPLOAD and errors pages served from www/errors. Each test opens the response in a new window.

GET

Static page

Fetch a static HTML page that says hello and welcome.

GET/hello.html
-> 200

Static file

Fetch a plain text file served by the /files location.

GET/files/hello.txt
-> 200

CGI with query string

Execute a CGI script (env.py) using GET with query parameters.

GET /cgi-bin/env.py?foo=bar&x=42
-> 200
POST

CGI with body

Send a request body to a CGI script

POST /cgi-bin/env.py
-> 200
UPLOAD

File upload

Send a raw body to POST /upload/<filename> — the server saves the request body into the upload directory.

POST /upload/<filename>
-> 200
The uploaded file is served back at /upload (autoindex on).
DELETE

DELETE file

Delete a file from the upload directory.

DELETE /upload/<filename>
-> 204
Upload a file first, then delete it here by name.
ERRORS

Each error opens the matching custom page from www/errors in a new window.

400 — Bad Request

POST an empty filename to the upload location: the URI is /upload/ with no file name.

POST /upload/ - filename vide
-> 400 + www/errors/400.html

403 — Forbidden

Read a file that has no read permission. Lock the file, then TEST.

GET /files/hello.txt
-> 403 + www/errors/403.html

404 — Page Not Found

Request a resource which does not exist.

GET /does-not-exist.txt
-> 404 + www/errors/404.html

405 — Method Not Allowed

/ only allows GET, so DELETE is rejected.

DELETE /
-> 405 + www/errors/405.html

413 — Payload Too Large

POST a 1000-byte body to /tiny, which allows at most 100 bytes.

POST /tiny - 1000 octets
-> 413 + www/errors/413.html

431 — Request Header Fields Too Large

Send a GET request with a 20 KB custom header. The server caps headers at 16 KB, so the request is rejected.

GET / + X-Big: 20000 x 'a'
-> 431 + www/errors/431.html

500 — Internal Server Error

Execute a CGI script (crash.py) which exits with an error.

GET /cgi-bin/crash.py
-> 500 + www/errors/500.html

501 — Not Implemented

Send a method webserv does not implement.

PATCH /
-> 501 + www/errors/501.html

502 — Bad Gateway

Execute a CGI script (sigsegv.py) which dies from a signal.

GET /cgi-bin/sigsegv.py
-> 502 + www/errors/502.html

504 — Gateway Timeout

Execute a CGI script (slow.py) which sleeps longer than the CGI timeout.

GET /cgi-bin/slow.py
-> 504 + www/errors/504.html
This test takes about 30 seconds (server CGI timeout).
